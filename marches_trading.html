Comprendre les marchés

Où peut-on trader ?

Tous les marchés ne fonctionnent pas de la même manière. Avant de choisir une stratégie, il faut comprendre l'environnement dans lequel elle sera utilisée.

MARCHÉ DES DEVISES

Forex

Le Forex est le marché sur lequel les devises sont échangées les unes contre les autres.

EXEMPLE EUR/USD
LIQUIDITÉ Élevée
VOLATILITÉ Variable
Exemple : EUR/USD, GBP/USD, USD/JPY
MARCHÉ ACTIONS

Actions

Une action représente une fraction de propriété d'une entreprise cotée.

EXEMPLE AAPL
LIQUIDITÉ Variable
HORAIRES Sessions
Exemple : Apple, Microsoft, Tesla
COMMODITIES

Matières premières

Ce marché regroupe notamment l'or, le pétrole, le gaz et d'autres ressources négociées sur les marchés.

EXEMPLE GOLD
RISQUE Variable
FACTEURS Macro
Exemple : Or, pétrole, argent
ACTIFS NUMÉRIQUES

Cryptomonnaies

Les cryptomonnaies sont des actifs numériques connus pour leurs mouvements parfois très importants.

EXEMPLE BTC/USD
VOLATILITÉ Élevée
MARCHÉ 24/7
Exemple : Bitcoin, Ethereum
Comparaison

Les marchés ne se ressemblent pas

Comprendre ces différences permet d'éviter de traiter tous les marchés comme s'ils fonctionnaient de la même façon.

Marché Exemple Liquidité Volatilité Particularité
Forex EUR/USD Élevée Variable Paires de devises
Actions AAPL Variable Variable Entreprises cotées
Or GOLD/USD Élevée Variable Matière première
Crypto BTC/USD Variable Souvent élevée Marché 24/7
